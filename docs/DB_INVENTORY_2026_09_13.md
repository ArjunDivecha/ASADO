# ASADO database inventory — 2026-09-13

A complete, point-in-time listing of **every table and view** in both ASADO databases, plus the
Neo4j graph. Generated by reading the live databases on 2026-09-13; warehouse and loop content
reflect the 2026-09-11/12 nightly runs, prediction markets reach 2026-09-13.

This is a **snapshot**, not a live document. `docs/factor_reference.md` is the auto-generated
per-variable reference, but it covers only the main warehouse — the loop database below appears
in no generated doc, which is why this file exists.

## Known gaps and stale surfaces (as of this snapshot)

Recorded here rather than quietly left for a reader to discover:

- `predmkt_resolutions` is **empty** (0 rows).
- `release_events_daily` / `release_events_signals` stop at **2026-07-10**.
- The `tariff_intensity_by_country` prediction-market signal stopped at **2026-07-01** — the tariff
  markets it read expired and no replacements were discovered, so no row is written at all.
- `predmkt_market_meta` holds 59 markets while `predmkt_daily` holds 140: **81 markets have price
  history with no metadata row**, because meta is rebuilt from the currently-discovered universe.
- `graph_features_daily` (v1) ends **2026-08-21**; it was retired in favour of `graph_features_pit_daily`.
- `price_state_daily` / `price_state_surface` hold only the latest day by design.
- Forward-return variables (`1DRet/5DRet/20DRet/60DRet/120DRet`, `1MRet…12MRet`) are optimizer
  **targets**, permanently blacklisted as predictors. On non-trading days `1DRet` is a literal `0.0`
  — join `daily_calendar` before computing any return or volatility statistic.
