# MacroState research package

**Start with [the final research plan](RESEARCH_PLAN.md).** This is the debate and research specification requested by Arjun, using existing ASADO data only. It is not an implementation PRD or a tested forecasting model.

| File | Purpose |
|---|---|
| [RESEARCH_PLAN.md](RESEARCH_PLAN.md) | Verdict, architecture choices, all 16 concepts, fair model contest, target/clock, inference, kill criteria, stages, and answers to all 20 seed questions. |
| [DATA_AUDIT.md](DATA_AUDIT.md) | Current data coverage and historical replay eligibility findings. |
| [candidate_catalog.csv](candidate_catalog.csv) | Source-qualified candidate mappings and proposed admission/transform treatment. |
| [universe_inventory.csv](universe_inventory.csv) | Broad inventory of existing tidy table/variable/source surfaces; entries are not independent features. |
| [PRIOR_RESEARCH.md](PRIOR_RESEARCH.md) | ASADO and cross-project results, exact scope of prior failures, and current harness limitations. |
| [LITERATURE_CHECK.md](LITERATURE_CHECK.md) | Independent audit of the closest country-index literature and complexity counterargument. |
| [DEBATE_RESOLUTION.md](DEBATE_RESOLUTION.md) | Independent review disagreements and the final decisions. |
| [SAKANA_REVIEW.md](SAKANA_REVIEW.md) | Raw independent Sakana consultation; advisory, not empirical evidence. |
| [SAKANA_USAGE.json](SAKANA_USAGE.json) | Provider-reported consultation usage. |

Other CSV/JSON files are audit support, not fitted model outputs. Prior results were read, not rerun. No new factor collection, predictive experiment, production code change, or deployment was performed. The original `MacroStateModel.md` remains untouched.

Workspace-relative source: `../../MacroStateModel.md`.
